# Technical coverage matrix

This inventory describes evidence for the 38 resource types in Databricks CLI 1.20.0's bundle schema. It is not a claim of universal CLI, backend, or service support. The current schema count comes from the pinned CLI, not the stale, gitignored `fixtures/golden/bundle_config_schema.json`.

All deployable golden plans are consumed by `fixtures/tooling/generate_expected.sh` and the shared Python/JavaScript fixture tests. Golden presence establishes only the state and behaviors present in that plan. Synthetic and semantic tests are explicitly not live backend evidence. Fixture selection does not change regression inclusion: all golden plans remain part of golden and public consumer tests.

## Evidence classes

- **Live golden (L):** retained CLI 1.20 capture from the default fixture workspace. It is not a fresh availability check.
- **Historical live (H):** a retained capture from an older CLI. It does not establish CLI 1.20 behavior.
- **Source-backed synthetic (S):** constructed plan grounded in pinned CLI/schema or SDK source. It does not establish backend acceptance.
- **Semantic/unit/interaction (U):** consumer-level contract tests or UI interactions, not a workspace capture.
- **Capability-required:** the behavior needs a service, permission, identity, or workspace capability not established by current evidence.
- **Uncovered/unverified (?):** no evidence currently establishes the behavior. This is not by itself a confirmed product defect.
